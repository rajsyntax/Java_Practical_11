# 🔄 Palindrome Checker

## 📌 Overview
A simple Java program that checks whether a given String is a palindrome or not.

A palindrome reads the same forward and backward.

Example:

```text
madam
```

Output:

```text
Palindrome
```

## 📁 Project Structure

```text
PalindromeChecker/
└── Main.java
```

## 🧠 Concepts Used
- `Scanner`
- `String`
- Loops
- String manipulation
- Conditional statements

## 💡 Logic

```text
Enter String
     ↓
Reverse the String
     ↓
Compare with Original
     ↓
Palindrome or Not
```
